# Poople Solver

This project is a fun development project to solve the popular [Poople](https://poople.io/) 
game. It is a restricted version of the famous [Word Ladder](https://leetcode.com/problems/word-ladder/description/) 
algorithmic problem. Even though it's been solved with standard solutions 
and other solvers have been written, there are a few reasons I wanted to make 
one myself.

## I've done it before

- I actually solved this problem in uni (pre-AI)
- This is a cool way to re-use my code from then

## AI Experience

- I want to see the power of generative AI to create UIs declaratively
- I had sketches of page designs that would be tedious to manually make but trivial for an LLM to create
